# Project guidance

- Read and follow [CONTRIBUTING.md](CONTRIBUTING.md) before making changes.
- Follow the task's requirements, requested format, and time budget. Keep changes focused.
- Use the project's package manager, scripts, conventions, and installed React Native/Expo versions. Apply relevant skills without imposing a different stack.
- Back review findings with a location, triggering condition, and concrete consequence. Separate defects from assumptions and optional improvements.
